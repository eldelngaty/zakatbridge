# ZakatBridge Roadmap

This roadmap is a living document. Timelines are intentionally not promised — progress depends on volunteers. Suggestions are welcome via issues.

## ✅ Phase 0 — Prototype (current)

- [x] Responsive bilingual (Arabic/English) static site with RTL
- [x] Separate Zakat and Sadaqah categories
- [x] Fictional demo case directory with filters
- [x] Simulated donation flow (no real money)
- [x] Demo transparency dashboard
- [x] Simple Zakat calculator
- [x] Open-source documentation (README, CONTRIBUTING, Code of Conduct, Security)

## 🔨 Phase 1 — Improve the Prototype

- [ ] Native-speaker and scholarly review of Arabic text and Zakat explanations
- [ ] Move demo cases and translations into separate JSON files
- [ ] Expanded calculator: more asset categories, Hijri date reminder, printable summary
- [ ] Automated accessibility checks and simple unit tests for calculator logic
- [ ] Dark mode and high-contrast mode
- [ ] Optional additional language (e.g. French for Canadian users)

## 🔍 Phase 2 — Research & Design (no real money)

- [ ] Interview community members about needs and trust concerns
- [ ] Draft a beneficiary dignity and privacy policy with community advisors
- [ ] Design a case verification model (field partners, documentation, audits)
- [ ] Research legal requirements in Canada, the United States, and Egypt
- [ ] Design an open transparency-reporting format (funds received, delivered, overhead)

## 🤝 Phase 3 — Partnerships (only if Phase 2 succeeds)

- [ ] Explore working with properly registered nonprofits in each country
- [ ] Evaluate licensed payment processors (the platform should never handle card data directly)
- [ ] Independent security and privacy review
- [ ] Pilot with a small number of verified cases, publicly reported

## Out of Scope (for now)

- Collecting or holding real funds directly
- Storing personal or financial information
- Cryptocurrency or speculative financial features
